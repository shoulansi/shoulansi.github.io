# Project Work

### Rock Climb Together — LaunchCode Unit 1 Project

**Description:**  
Rock Climb Together is an application made for rock climbers to easily create and join events.

**Features:**
- Built event creation using controlled form inputs and validation
- Added day-based filtering using conditional rendering and array filtering
- Implemented user join functionality with dynamic updates

**Tech Stack:** JavaScript, HTML, CSS, React
